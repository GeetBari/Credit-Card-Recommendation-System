# Credit Card Recommendation System

A machine learning-based system that recommends the most suitable credit card for a user based on input features such as income, age, employment status, and spending patterns. The system uses models like Random Forest, XGBoost, and KNN to generate predictions.

## Features
• Clean and structured dataset preprocessing

• Multiple ML algorithms for robust prediction

• Real-time recommendation based on user input

• Simple and intuitive web-based interface

## Installation
Clone the repository and install the required dependencies:


```bash
git clone https://github.com/AdvaitBothe1105/Credit-Card-Recommendation-System.git
cd credit-card/backend
pip install -r requirements.txt
```

## Usage

Run the backend Flask server:

```python
python app.py
```
Open the frontend in your browser (e.g., index.html) and enter the required user details. The system will predict and recommend the best-suited credit card.

## Models Used
• Random Forest

Each model is trained, evaluated, and tested to ensure accurate recommendations.
